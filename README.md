# Spam Email Detection Using Machine Learning

## Project Description
This project detects whether a message is spam or not spam using Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Google Colab

## Algorithm Used
- Multinomial Naive Bayes

## Features
- Text preprocessing
- Spam classification
- Accuracy evaluation
- Confusion matrix

## Dataset
SMS Spam Collection Dataset

## Output
Predicts:
- Spam
- Not Spam
